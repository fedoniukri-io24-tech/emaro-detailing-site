# Emaro Premium Auto Care

Сайт мобільного детейлінгу Emaro (Warszawa). Локалі: `/uk`, `/pl`.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте [http://localhost:3000/uk](http://localhost:3000/uk) або [http://localhost:3000/pl](http://localhost:3000/pl).

## Збірка

```bash
npm run build
npm start
```

## Структура

- `src/app/` — Next.js App Router, сторінки та компоненти
- `src/i18n/` — словники українською та польською
- `public/images/emaro/` — логотип, hero, галерея

## Деплой

Проєкт готовий для Vercel / будь-якого Node-хостингу з підтримкою Next.js 14.
